# LAB React · Primera etapa

Aplicación React + TypeScript + Vite aislada del sitio original en la raíz del repositorio.

## Ejecutar

Requiere Node.js compatible con Vite.

```bash
cd react-app
npm install
npm run dev
npm test
npm run build
```

## Funcional ahora en código

- 12 geometrías SVG seleccionables.
- Composición modular SVG con filas, columnas, densidad, rotación, mezcla y paleta.
- Semilla determinista editable y botón de nueva semilla.
- Exportación SVG.
- Pruebas unitarias de semilla y SVG.
