# Exportación
- SVG: exportación vectorial del documento 2D.
- PNG: renderización local de SVG en canvas.
- WebM: grabación de la vista 3D con MediaRecorder cuando el navegador lo soporta.
- GIF y MP4: aún no implementados; no mostrar opciones que no funcionen.
- Exportación de escena mixta 2D/3D: pendiente.
